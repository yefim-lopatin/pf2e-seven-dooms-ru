# Семь бедствий Сэндпойнта — русский перевод для Foundry VTT

Неофициальный модуль Babele для Seven Dooms for Sandpoint. Перевод включает все девять глав, описание города, инструменты ведущего, руководство игрока, раздаточные материалы, карточки существ и предметов, подписи сцен и окна макросов.

Основной русский источник — Seven_Dooms_for_Sandpoint_v0.7.3.pdf, перевод RpgLeshiy. Недостающие в PDF разделы переведены по оригиналу с соблюдением общего словаря. Карты, изображения и музыка загружаются из установленного официального модуля.

## Требования

Foundry VTT 14.368, Pathfinder 2e 8.5.1, приобретённый официальный модуль pf2e-ap200-seven-dooms-for-sandpoint 14.1.0, Babele 2.9.1, pf2e-ru 2.2.2 и ru-ru 14.367.5. Также нужен lib-wrapper 1.13.5.1, который требуется Babele, pf2e-ru и этому переводу.

## Установка

После публикации выпуска модуль можно установить через «Дополнительные модули → Установить модуль», вставив адрес манифеста:

https://github.com/yefim-lopatin/pf2e-seven-dooms-ru/releases/latest/download/module.json

Для ручной установки:

1. Распакуйте ZIP. Поместите папку pf2e-seven-dooms-ru в Data/modules вашего Foundry.
2. Перезапустите Foundry и откройте отдельный чистый мир Pathfinder 2e.
3. Включите официальный модуль приключения, перечисленные зависимости и «Семь бедствий Сэндпойнта — неофициальный русский перевод».
4. Выберите русский язык, перезагрузите мир и импортируйте приключение через официальный импортёр.

Обновление перевода само по себе не изменяет ранее импортированные документы. Для получения переведённого приключения нужен новый импорт. Перед повторным импортом в существующую кампанию сохраните резервную копию мира.

Команды макросов, характеристики, правила, ссылки, формулы и геометрия сцен сохраняются. Русские подписи окон макросов и некоторых системных полей показываются отдельным слоем отображения. При редактировании системного поля видна его исходная запись, чтобы перевод не менял игровые данные.

## Проверка версии 0.1.0

В отдельном мире выполнен настоящий чистый импорт. Проверены все 10708 текстовых полей перевода и все 2069 вложенных предметов после замен официального импортёра; характеристики, формулы, права, геометрия и команды 65 макросов совпали с исходным английским импортом. В интерфейсе проверены журналы, раздатки, руководство игрока, карточки разных типов, броски, макросы, заметки, регионы и права обычного игрока. Все 14 особых маскировочных имён токенов сохранены.

Известное ограничение официального модуля 14.1.0 в Foundry 14.368: макрос «Покинуть тело» с выбранным токеном вызывает отсутствующий метод сетки getTopLeft и останавливается до изменения персонажа. Та же ошибка воспроизводится исходной английской командой без перевода на квадратной сетке и сцене без сетки. Команда сохранена без изменений; исправление этого макроса не входит в локализацию. Без выбранного токена его русское уведомление работает.

## Источники

Это отдельный модуль локализации. Он не содержит коммерческих карт, иллюстраций, музыки, баз данных или PDF. Указание авторов и источников находится в [NOTICE.md](NOTICE.md).

## Обновление 0.1.1

Ссылка «Услуги заклинателя» открывает русскую справку с ценами внутри Foundry. Все 22 городских тега показывают описания из руководства игрока при наведении. Обычные записи кубиков в журналах, описаниях предметов и существ, а также карточках чата доступны для броска нажатием. Уже оформленные броски сохраняются.

Для этих трёх исправлений достаточно обновить модуль и перезагрузить окно Foundry. Повторный импорт приключения не требуется: сохранённые документы мира не изменяются.
